## 1. Phát hiện

### AUR-01 — P1 · Migration trong repo chứa RPC hỏng (`meal.id`) — repo không dựng lại được DB

- **File:** `supabase/migrations/20261030163455_atomic_shopping_writes.sql` (và bản chép lại trong `20261031121500_harden_save_shopping_data_guard.sql`):
  ```sql
  insert into public.meal_ingredients(user_id, meal_id, ingredient_id, position)
    select v_user_id, meal.id, ingredient.value::uuid, (ingredient.ordinality - 1)::smallint
    from pg_catalog.jsonb_array_elements(p_data->'meals') as meal(value)
  ```
  Alias `meal(value)` chỉ có cột `value`; `meal.id` không tồn tại.
- **Chạy thật trên bản sao dựng từ repo:** cả payload rỗng và payload có 1 meal đều trả `ERROR: column meal.id does not exist`. Vì là câu lệnh thường (không nằm trong nhánh if), **mọi lần lưu Weekly Plan/thư viện đều thất bại**.
- **Nhưng prod KHÔNG hỏng:** `pg_get_functiondef` trên `mpuxleglzmoaexdjgerp` trả `(meal.value->>'id')::uuid` — bản đúng. DB được vá bằng migration `20261031011716 fix_save_shopping_data_meal_id_reference`, **file này không có trong repo** (xem AUR-15).
- **Hệ quả thật:** `supabase db reset` / dựng môi trường mới / CI từ repo sẽ ra một DB mà **không ghi được dữ liệu**, im lặng với người dùng (`updateData()`, `page.tsx:186-193`, chỉ toast; `saveErrorMessage` không match nên rơi về câu chung "Không lưu được dữ liệu lên Supabase."). Đây là bom hẹn giờ cho mọi lần reset dev, review môi trường, hay handover.
- **Bản vá đã kiểm chứng:** đổi `meal.id` → `(meal.value->>'id')::uuid`, chạy lại: save OK, rows = `{ingredients:1, meals:1, meal_ingredients:1, weekly_plan_meals:1, weekly_plan_products:1}` — đúng bằng nội dung function đang chạy ở prod.
- **Lịch sử:** `git log -S "meal.id"` → chỉ có từ commit `c23b81a`; `git log -S "(meal.value->>'id')"` → **không có commit nào**. Bản vá tồn tại trên DB từ 2026-10-31 nhưng chưa bao giờ được commit.

### AUR-15 — P1 · Migration drift: repo thiếu 2 migration đang chạy trên prod, 1 migration lệch version

`supabase_migrations.schema_migrations` của `mpuxleglzmoaexdjgerp` có 8 bản ghi, đối chiếu với 6 file trong `supabase/migrations/`:

| 20261030163455 | atomic_shopping_writes | ✅ (nhưng nội dung **sai**, AUR-01) |
| 20261030170159 | import_notion_seed_user | ✅ |
| **20261031011716** | **fix_save_shopping_data_meal_id_reference** | ❌ **thiếu** |
| **20261101040902** | **harden_save_shopping_data_guard** | ⚠️ nội dung tương tự nhưng repo đặt version `20261031121500` — version này **chưa từng** được apply |

Cách sửa: `supabase db dump --schema` hoặc đọc `pg_get_functiondef` từng object để backfill 2 migration thiếu vào repo, đổi tên file `20261031121500` → `20261101040902` cho khớp, rồi commit `20261031011716` với nội dung đúng.
